# Zero to Mastery Project Files

This directory contains a **Simplefolio** project completed as part of the **Zero to Mastery** curriculum.

## About this project

Simplefolio is a minimal developer portfolio template designed to showcase:

- Personal introduction / hero section
- About section
- Project showcase cards
- Contact section
- Social links footer

It uses modern frontend tooling and styling, including:

- HTML5
- SCSS / Sass
- Bootstrap
- JavaScript
- Parcel (for bundling)

## Folder contents

In this folder you will find the source files used to build and customize the portfolio, including:

- Main page structure and sections
- Styling files for colors, layout, and responsiveness
- Asset references (images, resume, project screenshots)
- Configuration and package files for running the project locally

## Getting Started

### Prerequisites

Make sure you have these installed:

- [Git](https://git-scm.com/)
- [Node.js](https://nodejs.org/) (includes npm)

### Installation

From your terminal:

```bash
# Go into the project folder
cd simplefolio

# Install dependencies
npm install
```

### Run the project

```bash
# Start development server
npm start
```

Then open:

`http://localhost:1234/`
